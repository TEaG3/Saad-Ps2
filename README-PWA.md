# Saad PS2 Artwork Station

نسخة قابلة للتثبيت كتطبيق ويب تقدمي (PWA) من أداة إدارة أغلفة وأيقونات ألعاب PlayStation 2.

## التثبيت
- **Android / Chrome أو Edge:** افتح الموقع ثم اضغط «تثبيت التطبيق» أو اختر «تثبيت التطبيق» من قائمة المتصفح.
- **iPhone / iPad:** افتح الموقع في Safari، اضغط «مشاركة»، ثم «إضافة إلى الشاشة الرئيسية».

## العمل دون اتصال
يقوم Service Worker بتخزين واجهة التطبيق الأساسية بعد أول زيارة. بعض الوظائف التي تحتاج الإنترنت، مثل جلب صور الأغلفة، ستظل بحاجة إلى اتصال.

## ملاحظة مهمة عن USB
اختيار المجلدات والكتابة المباشرة إلى USB تعتمد على دعم المتصفح ونظام التشغيل. التثبيت كتطبيق لا يزيل قيود صلاحيات الملفات في iOS/iPadOS.
